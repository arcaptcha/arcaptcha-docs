# ایجنت

اگر از **Claude Code**، **Cursor** یا هر ایجنت کدنویسی دیگری استفاده می‌کنید، می‌توانید ویجت **آرکپچا** را بدون نوشتن کد یکپارچه‌سازی به پروژه خود اضافه کنید.

1. مهارت [ARCaptcha skill](/downloads/arcaptcha-skills.zip) را دانلود کنید و به پروژه خود اضافه کنید.
2. **Site Key** خود را در پرامپت خود قرار دهید. **Secret Key** را در یک متغیر محیطی نگه دارید و هرگز آن را در کد سمت کاربر قرار ندهید.
3. از دستیار بخواهید یک فرم را با آرکپچا محافظت کند؛ برای مثال:
   `Add ARCaptcha to the signup form and verify the token on the server`

دستیار به‌صورت خودکار اسکریپت ویجت را بارگذاری می‌کند، کانتینر `arcaptcha.` را به فرم اضافه می‌کند و API مربوط به اعتبارسنجی را فراخوانی می‌کند.

اگر ترجیح می‌دهید اضافه کردن ویجت را به‌صورت دستی انجام دهید، می‌توانید مراحل مشابه را در بخش [نصب](/fa/installation) مشاهده کنید.
